# MoneyAI - Кабинет аналитики финансов

Прототип личного кабинета для аналитики финансовых данных с интеграцией Kaspi API.

## 📋 Описание

Это прототип дизайна для системы аналитики финансов, которая позволяет:
- Пользователям регистрироваться и подключать свой Kaspi кабинет по API
- Получать данные о продажах и транзакциях из Kaspi и вашего сайта
- Просматривать аналитику по формулам (продажи за период, расходы по категориям и т.д.)
- Работать в нескольких ролях (Пользователь, Аналитик, Администратор)

## 🚀 Запуск проекта

### Требования
- Node.js 18+
- npm или yarn

### Установка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production версии
npm run build

# Запуск production сервера
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 👥 Роли пользователей

### 1. Пользователь (User)
- Регистрация и вход в систему
- Подключение Kaspi API через личный кабинет
- Просмотр своей финансовой аналитики
- Управление личными настройками

### 2. Аналитик (Analyst)
- Все возможности пользователя
- Расширенная аналитика и отчеты
- Доступ к данным нескольких пользователей (если предоставлено)
- Экспорт данных

### 3. Администратор (Admin)
- Полный доступ ко всем функциям
- Управление пользователями
- Настройка интеграций
- Системные настройки

## 📊 Функционал дашборда

### Статистические карточки
- Общий баланс
- Доходы за период
- Расходы за период
- Накопления

### Графики
- Динамика доходов и расходов (по месяцам)
- Расходы по категориям (круговая диаграмма)

### Таблица транзакций
- Дата операции
- Мерчант/получатель
- Категория
- Сумма
- Тип (доход/расход)

## 🔌 Интеграции (будущая реализация)

### Kaspi API
Для подключения Kaspi API потребуется:
1. Авторизация в Kaspi Business
2. Получение API ключей
3. Настройка OAuth 2.0 flow
4. Синхронизация транзакций

### API вашего сайта
- REST API endpoint для получения данных о продажах
- Webhook для实时更新 данных
- Формулы для расчета метрик
